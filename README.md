# food_recipe_webpage_crud
Receptgyűjtemény

Étrend követéshez létre hozott honlap. A naptárban el lehet menteni minden étkezést.Az adott napot megnyitva drag and drop lehet változtatni az étkezések sorrendjét. A keresősávban már létrehozott receptek között lehet keresni név vagy hozzávaló alapján vagy csak egy üreskeresést futtatni. Lehet rétrehozni, törölni, szerkeszteni a recepteket. A receptek létrehozásakor minden fontos információt meg lehet adni:név, elékészítési idő, tipus,hány főre, hozzávalók és leírás.

Minden inputnál automatikusan felkínál lehetőségeket gépelés közben az adatbázisban szereplő ételek és hozzávalók alapján.
